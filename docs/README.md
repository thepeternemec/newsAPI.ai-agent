# Historical architecture documents

The current project is the **free newsAPI agent** community resource website. Start with the [repository README](../README.md), [contribution guide](../CONTRIBUTING.md), and [website guide](https://newsapi-ai-agent.vercel.app/docs).

Other documents in this directory describe the inherited Pleiades prototype and earlier rollout plans. They are retained for project history. Their endpoints, SDKs, ingestion plans, freshness claims, hosted-MCP proposals, and pricing discussions do not describe the current community site or official NewsAPI.ai service.

Current official resources are cataloged in `apps/web/data/resources.json`. The deployed site uses NewsAPI.ai’s published MCP and n8n documentation rather than operating its own integration backend.
